# 项目级澄清：会员管理系统第一版（可运行 + 登录）

## 1. 目标用户与目标

**用户**：内部管理员。首版只有一个管理员角色，负责登录后查看会员总览。

**目标**：交付一个本地可启动、可登录的会员管理系统最小闭环，让负责人能够实际运行并验证登录流程，为后续会员维护能力打基础。

**成功标准**：一条命令能启动；管理员能登录；登录后能看到会员总览；未登录无法访问受保护页面。

## 2. 核心流程

1. 负责人执行 `npm start`，服务监听本地端口并打印访问地址。
2. 浏览器打开登录页，输入管理员账号和密码。
3. 服务端校验 scrypt 密码哈希，创建服务端会话并下发 `HttpOnly` Cookie。
4. 浏览器携带 Cookie 访问会员总览页，看到只读会员名册。
5. 点击退出，服务端销毁会话，再访问受保护页面时被重定向回登录页。

## 3. MVP 边界（做 / 不做）

**做：**

- 登录页、登录成功后的会员总览页、退出登录。
- 预置管理员种子账号；密码以 scrypt 哈希存储，不保存明文。
- 服务端内存会话 + `HttpOnly`、`SameSite=Lax` Cookie。
- 未登录访问受保护页面时重定向到登录页。
- 只读会员名册（内置少量示例数据），作为“会员管理”的基本载体。
- `GET /healthz` 健康检查、`node:test` 自动化测试、README 启动说明、`.env.example`。
- 统一登录失败文案与简单失败限流，避免账号枚举和暴力尝试。

**不做：**

- 会员自助注册、找回密码、短信/邮箱验证。
- 角色权限矩阵、多租户、SSO、第三方登录。
- 会员新增/编辑/删除、等级、积分、订单、支付、导入导出（放 C2/C3）。
- 生产级数据库、Redis、容器编排、云部署。
- 前端框架、复杂视觉设计或响应式大屏。
- 生产高可用与持久化会话（放 C4）。

## 4. 技术栈与部署

| 项目 | 决策 | 理由 |
|---|---|---|
| 运行时 | Node.js 22+ | 环境通用，单进程即可运行 |
| Web 层 | Node 内置 `http` 模块 | 首版零运行时依赖，安装/启动失败面最小 |
| 数据 | 本地 JSON 文件（`data/db.json`） | 首版无需数据库服务；后续可替换为 SQLite/PostgreSQL |
| 密码 | `crypto.scrypt` + 随机盐 | 不引入第三方库也不存明文 |
| 会话 | 服务端内存 Session + 随机 Cookie ID | 首版单实例足够；重启后需重新登录 |
| 前端 | 服务端渲染 HTML + 少量原生 JS/CSS | 减少构建链，保证开箱即用 |
| 测试 | `node:test` + 内置 `assert` | 无额外依赖，可直接在 CI 运行 |
| 部署 | 本机 `npm start`，环境变量配置端口/凭据 | 第一版先跑起来，不引入部署平台 |

**目录约定**：`src/` 服务端代码，`public/` 静态资源，`test/` 自动化测试，`data/` 运行时数据（不进 git）。

**命令**：`npm start` 启动；`npm test` 测试；`npm run check` 语法/风格检查（使用 `node --check`）。

## 5. 非功能要求

- **安全**：scrypt 哈希 + 恒定时间比较；Session ID 随机；Cookie `HttpOnly`/`SameSite=Lax`，生产启用 `Secure`；HTML 转义；不提交真实凭据。
- **性能**：首版单实例、低并发；内存会话与本地 JSON 足够，不做压测承诺。
- **可用性**：启动失败时打印可操作的错误信息；数据文件缺失时自动初始化。
- **可维护性**：路由、认证、存储分层；关键行为有集成测试；无运行时第三方依赖。
- **合规**：首版不采集敏感个人信息；示例会员数据使用虚构姓名和脱敏手机号。

## 6. 约束与未知项

以下为按“第一版先跑起来”原则采用的默认假设；负责人如无异议，GR 通过后按此执行：

1. 首版是内部管理员工具，不面向公网多租户场景。
2. 开发默认管理员账号为 `admin` / `admin12345`，仅用于本地演示；生产必须通过环境变量覆盖，README 会显著提示。
3. 首版会员数据只读，新增/编辑/停用放到 C2。
4. 界面以中文为主，桌面浏览器优先。
5. 数据文件路径允许通过 `DATA_FILE` 环境变量覆盖，便于测试隔离。
6. 会话保存在内存，重启后需重新登录；这是 V1 明确接受的限制。

## 7. 交付边界

首版交付包含：可运行代码、自动化测试、启动文档、环境变量样例、FlowGate 变更记录。

不包含：生产部署、HTTPS 证书、数据库迁移、压测报告、会员写操作。
