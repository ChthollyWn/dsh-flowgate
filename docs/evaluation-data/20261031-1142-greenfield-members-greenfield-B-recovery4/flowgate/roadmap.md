## 变更说明

### C0 · 工程骨架

- 建立 `package.json`（`start`、`test`，无第三方依赖）。
- Node HTTP 服务入口、配置读取、静态文件服务。
- `GET /health` 健康检查。
- 登录页占位与基础样式。
- 测试基线（健康检查、静态页可访问）。
- README：环境要求、启动、测试、目录说明。

### C1 · 登录、会话与会员列表

- 预置管理员（密码 scrypt 哈希，支持环境变量覆盖）。
- `POST /api/login`、`POST /api/logout`、`GET /api/me`。
- 服务端会话与 HttpOnly Cookie；受保护路由拦截。
- 登录页接入真实接口，包含错误提示与加载状态。
- `GET /api/members` 返回预置会员；登录后渲染会员列表。
- 自动化测试覆盖登录成功、密码错误、未登录拦截、退出后失效。
- README 补充默认账号与安全提示。

## 后续候选（v1 之后，不在本次范围）

- C2：会员新增/编辑/停用与字段校验。

- C5：导入导出、搜索与分页。

- v1 以 C0 + C1 全部验收通过为准。
- C2+ 仅作为方向记录，不纳入本次交付。
